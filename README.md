# Converge

Practical team formation for hackathons — clearer presence and structured connect flows without Discord-channel hunting.

## Product thesis

Replace inefficient chat-based teammate hunting with: light join → useful profiles → pre-event connect and/or day-of map presence → meet up.

**Deferred:** recommendation engines, compatibility ranking, full auto-formation, native apps.
