# Converge — Project Context

## What
Practical team-formation for hackathons (and later other team-based events). Beats Discord-channel hunting with clearer presence, lighter social friction, and structured connect flows.

## Client
**Web-first** on **Next.js** — see [medium.md](medium.md). No app-required join.

## Optimization meaning (for now)
High-level product optimization: better process and UX than chat boards — not algorithmic recommendation yet.

## Current phase
UX definition in order: auth → onboarding → **pre-hackathon** → day-of → then execution.

## Explicitly deferred
Recommendation engines, compatibility ranking, full team auto-formation algorithms; native apps.
