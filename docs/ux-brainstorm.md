## Product thesis
Converge replaces inefficient chat-based team hunting with: light join → useful profiles → pre-event connect and/or day-of map presence → meet up.

## Locked leanings (summary)
- Auth0 (one app); Google only; progressive access
- Client: responsive web on **Next.js**; shareable link/code; no install gate
- Org event: timeline, ≥1 track, required max team size, TBA venue OK
- Candidate: Join CTA collects min profile; skills chips+tags; single role; experience; desired team size; optional org
- Optional resume → agent autofill; socials default public to signed-in, opt-out private; never signed-out
- Nickname always editable (Grok); Grok Imagine avatar
- Day-of realtime map; AirTag-like finder; indoor coarse + warmer/colder
